# 跨平台部署（macOS / Windows）

代码本身是跨平台的（Python 3.8+ 标准库 + `curl`），差异只在**配置路径**和**开机自启方式**。

---

## 一、依赖

| 平台 | 需要 |
|---|---|
| Windows 10/11 | Python 3.8+、`curl`（系统自带） |
| macOS | `python3`（系统自带或用 Homebrew 装）、`curl`（自带） |

不需要 `pip install` 任何东西。

---

## 二、配置路径（代码已自动识别）

| 平台 | Clash Verge 配置目录 |
|---|---|
| Windows | `%APPDATA%\io.github.clash-verge-rev.clash-verge-rev` |
| macOS | `~/Library/Application Support/io.github.clash-verge-rev.clash-verge-rev` |
| Linux | `~/.config/io.github.clash-verge-rev.clash-verge-rev` |

如果装在别处，用环境变量覆盖：

```bash
export CLASH_OPT_VERGE_DIR="/custom/path/to/config"
export CLASH_OPT_PROXY="127.0.0.1:7897"
```

---

## 三、macOS 上要做的四件事

### 1. 同样关掉 Verge 的选择持久化

编辑 `~/Library/Application Support/io.github.clash-verge-rev.clash-verge-rev/profiles/Merge.yaml`：

```yaml
profile:
  store-selected: false
```

再在 `verge.yaml` 里确认：

```yaml
enable_auto_launch: true
enable_silent_start: true
```

> 不改这步会怎么样：Verge 会周期性把节点改回它记住的值，本工具每 15 秒拉回来一次，形成拉锯战。功能能用，但会有空窗。

### 2. 模式设成 rule

要么改 `config.yaml` 里的 `mode: rule`，要么在 Verge 界面里切。

`rule` 模式下国内流量直连，不占隧道上行——这一步本身就有收益。

### 3. 启动

```bash
cd /path/to/clash-opt
python3 clash_opt.py serve
```

或双击 `启动看板.command`（首次需 `chmod +x 启动看板.command`）。

浏览器打开 <http://127.0.0.1:8787>

### 4. 开机自启（launchd）

创建 `~/Library/LaunchAgents/com.clashopt.monitor.plist`：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
  "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key><string>com.clashopt.monitor</string>
  <key>ProgramArguments</key>
  <array>
    <string>/usr/bin/python3</string>
    <string>/Users/YOURNAME/clash-opt/clash_opt.py</string>
    <string>serve</string>
  </array>
  <key>WorkingDirectory</key><string>/Users/YOURNAME/clash-opt</string>
  <key>RunAtLoad</key><true/>
  <key>KeepAlive</key><true/>
  <key>StandardOutPath</key><string>/tmp/clashopt.log</string>
  <key>StandardErrorPath</key><string>/tmp/clashopt.err</string>
</dict>
</plist>
```

加载：

```bash
launchctl load ~/Library/LaunchAgents/com.clashopt.monitor.plist
```

`KeepAlive` 让它挂了自动重启——比 Windows 那边更省心。

## 四、两台机器分别测速，结果不通用

节点排名和**你所处的网络**强相关。家里、公司、不同运营商，最优节点可能完全不同。

`last_rank.json` 已经加到 `.gitignore`，不会互相污染。

## 五、跨平台代码约定（改代码时注意）

- 判断平台用 `IS_WIN` / `IS_MAC`（文件顶部已定义）
- 不要硬编码 `%APPDATA%`，用 `VERGE_DIR`
- 不要硬编码 `powershell`，进程内存用 `proc_mem_mb()`
- 路径一律 `pathlib.Path`
- 标准输出统一 UTF-8：Windows 上启动时加 `-X utf8`

## 六、git push 报 502 怎么办

现象：`git push` 报 `CONNECT tunnel failed, response 502`，但浏览器打开 github.com 正常。

原因：环境变量里的 `HTTP_PROXY` / `HTTPS_PROXY` 指向了另一个本地代理端口
（本机实测是 `127.0.0.1:53681`，不是 Clash 的 7897），git 优先读环境变量，就走了错的门。

给本仓库单独指定（只影响这一个仓库）：

```bash
git config --local http.proxy http://127.0.0.1:7897
git config --local https.proxy http://127.0.0.1:7897
```

排查用：

```bash
env | grep -i proxy          # 看有没有别的代理
curl -s -o /dev/null -w "%{http_code}\n" --proxy http://127.0.0.1:7897 https://github.com
```
